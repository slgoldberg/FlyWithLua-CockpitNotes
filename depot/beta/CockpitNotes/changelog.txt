================================================================================
FlyWithLua CockpitNotes - Changelog
================================================================================

Version 1.1.2 (Latest Channel - Templates SelectPulldown Fix)
--------------------------------------------------------------------------------
- Restored "Aviation Templates..." as a real ImGee SelectPulldown with ResizeNS
  open-menu cursor, circular mouse-wheel cycling across all 8 templates
  (wrap = true, natural_list_order = true), and Lens UI per-item tooltips.
- Added non-destructive buffer snapshot/restore: cycling away from item 0
  ("Aviation Templates...") snapshots the current note so returning to item 0
  restores your previous text without data loss; typing, clearing, or loading
  a note resets the picker cleanly to item 0.

Version 1.1.1 (Latest Channel - Templates Menu Fix)
--------------------------------------------------------------------------------
- Fixed the "Aviation Templates..." toolbar dropdown: replaced the stateful
  SelectPulldown (which re-applied template 1 on every wheel-down tick and
  clamped on wheel-up) with a one-shot action button and downward anchored
  popup menu (OpenPopupAtItem / BeginAnchoredPopup) with per-item tooltips.
  Templates now load only on explicit click, preventing accidental overwrites
  while browsing.
- Updated the About dialog capabilities list to accurately describe the
  anchored Aviation Templates action popup and SelectPulldown theme selector.

Version 1.1.0 (FlyWithLua 2.8.23+ & SkunkCrafts Updater 4.2.18+ Parity)
--------------------------------------------------------------------------------
- Upgraded to 5-theme ImGee SelectPulldown selector with mouse-wheel cycling,
  Lens UI per-item tooltips, and cross-window theme synchronization:
  Charcoal (Default), Rusty (Aviation), ImGui Dark, ImGui Classic, and
  Paper Light (with graceful fallback to ImGui Light on older builds).
- Added per-window Markdown base directory synchronization via
  imgui.MD.SetWindowBaseDir() on open, save, and note switch so relative local
  images and links resolve cleanly from the active note's folder.
- Added GFM Callout quick-insert menu actions (> [!NOTE], > [!TIP],
  > [!CAUTION]).
- Restored exact saved window geometry (position & size) on reopen.
- Replaced Unicode em-dash placeholders in default aviation templates and
  starter notes with clean ASCII "--" placeholders.
- Aligned SkunkCrafts Updater channel configs with the SCU 4.2.18+ multi-channel
  contract (zone|custom, canonical Stable module URL, main_name|Stable,
  channel.Latest pointing to the beta depot, and changelog|changelog.txt).
- Retired the frozen v1.0.0 release payload override; both Stable and Latest
  channels now stage cleanly from the canonical repository source with dynamic
  version stamping.
- Modernized CI to explicit workflow_dispatch SkunkCrafts Publish and
  beta-to-release Promotion workflows.

Version 1.0.2 (Beta Channel - Phase 3 Suite)
--------------------------------------------------------------------------------
- Cutting-edge Phase 3 build for FlyWithLua developmental release.
- Native C++11 file selection suite integration.
- imgui.FilePickerCombo microsecond directory scanning (200px width).
- In-cockpit native modal [Open...] and [Save As...] dialogs.
- Tactile font scaling from 50% to 200% with header zoom controls.
- Window resizing limits clamped to 720x280 minimum.
- Dual-bracket Markdown support: standard CommonMark [text](url) and ![alt](img)
  alongside legacy curly brackets.
- Silent non-intrusive startup: window stays hidden until summoned.
- Registered X-Plane command "FlyWithLua/CockpitNotes/toggle" for key/joystick binding.
- Added FlyWithLua macro "Cockpit Notes: Toggle".

Version 1.0.1
--------------------------------------------------------------------------------
- Silent non-intrusive startup: window stays hidden until summoned.
- Registered X-Plane command "FlyWithLua/CockpitNotes/toggle" for key/joystick binding.

Version 1.0.0 (Initial Modular Standalone Release)
--------------------------------------------------------------------------------
- Initial modular standalone release.
- Standalone in-cockpit Markdown scratchpad and flight notes system.
- Self-contained directory scanning compatible with all FlyWithLua versions.
- Live Markdown text editor with formatted preview.
- Multi-note storage in FlyWithLua/Scripts/CockpitNotes/notes/ with starter
  flight checklists, flight plan, and scratchpad templates.
- Multi-channel SkunkCrafts Updater integration.
