================================================================================
FlyWithLua CockpitNotes
================================================================================
An interactive in-cockpit Markdown scratchpad and flight notes system for
X-Plane 12 flight operations.

Features:
- Live Markdown text editor with formatted preview.
- Native in-cockpit file picker and modal Open / Save As dialogs.
- Tactile font scaling from 50% to 200%.
- Checklists and avionics status pills/badges.

Usage:
- Access via Plugins -> FlyWithLua -> FlyWithLua Macros -> Cockpit Notes
- Or bind command 'FlyWithLua/CockpitNotes/toggle' to a joystick button.
- Note files are saved in FlyWithLua/Scripts/CockpitNotes/notes/.
