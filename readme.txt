================================================================================
FlyWithLua CockpitNotes (v1.1.0)
================================================================================
An interactive in-cockpit Markdown scratchpad and flight notes system for
X-Plane 12 and X-Plane 11 flight operations (requires FlyWithLua 2.8.23+).

Features:
- Live Markdown text editor with Write, Split, and Preview modes.
- 5-theme ImGee SelectPulldown selector (Charcoal, Rusty, ImGui Dark,
  ImGui Classic, and Paper Light) with mouse-wheel cycling.
- Native in-cockpit file picker and modal Open / Save As dialogs with
  per-window relative base directory resolution for local images and links.
- GFM tables, checklists, callout blocks ([!NOTE], [!TIP], [!CAUTION]),
  and avionics status pills/badges.
- Tactile font scaling from 50% to 200%.

Usage:
- Access via Plugins -> FlyWithLua -> FlyWithLua Macros -> Cockpit Notes: Toggle
- Or bind command 'FlyWithLua/CockpitNotes/toggle' to a key or joystick button.
- Note files are saved in FlyWithLua/Scripts/CockpitNotes/notes/.
